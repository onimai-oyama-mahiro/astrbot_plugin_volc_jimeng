Cloudflare R2

参考图公网托管（方案 A：自定义域直连）

只给目标 bucket 的 Object Read & Write 权限；公共地址必须是自定义域，不要用 r2.dev（有限速，仅测试）。没配好之前请不要把「启用 R2」打开。

Cloudflare R2 配置步骤（方案 A）

目标：本地参考图 → R2 → 自定义域公共 URL → 即梦下载。全程不需要给 ECS 开公网文件服务。

  1. 创建 Bucket

    Cloudflare Dashboard → R2 Object Storage → Create bucket，名称如 astrbot-jimeng，Location 选 Automatic。

  2. 绑定自定义域（关键）

    进入该 Bucket → Settings → Custom Domains → Connect Domain，填一个已托管在 Cloudflare 的域名，例如 img.example.com，等状态变成 Active。

    不要用 pub-xxx.r2.dev：它是测试域，有几百请求/秒的限速，国内也不稳定。

  3. 创建 R2 API Token

    R2 → Manage R2 API Tokens → Create API Token，权限选 Object Read & Write，Scope 只选这个 Bucket。创建后保存 Access Key ID 和 Secret Access Key（Secret 只显示一次）。

  4. 回到「设置」填写

    Account ID 取自端点 https://<ACCOUNT_ID>.r2.cloudflarestorage.com；Bucket 填桶名；公共访问地址填自定义域（带 https://，结尾不要 /）；再填 R2 的 AccessKey / Secret 和前缀。

  5. 建议加生命周期兜底

    Bucket → Settings → Lifecycle rules，前缀填 jimeng/，设置 1 天后删除。插件默认生成完就删，生命周期是防止异常情况下残留。

  6. 测试

    在「设置 → Cloudflare R2」点 测试 R2 上传：会传一张 16×16 的测试图、通过公共地址读一次、再删除。成功会显示 URL 和耗时。

常见问题

先看这里
  • 为什么不用 r2.dev？限速、仅测试、国内不稳；自定义域才是生产路径。
  • 图片会公开吗？是。知道 URL 的人能访问；插件用 UUID 命名，并默认生成后删除。
  • 即梦报 50220？说明它拿到的不是公网 http(s) 图片：检查自定义域是否 Active、WAF/Bot Fight 是否拦截。
  • 需要配置 CORS 吗？不需要，上传和下载都是服务端行为。
  • R2 填错会怎样？插件会回退 AstrBot 文件服务；两者都不可用时会明确报错。
